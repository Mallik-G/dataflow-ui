# EditEntityMappingsPage - Function Documentation

## Core Functions

### `createInitialMappings(rawCols, curatedCols)`

**Location**: Lines 297-334
**Purpose**: Creates initial column mappings between raw and curated columns using fuzzy matching
**Parameters**:

- `rawCols` (string[]): Array of raw column names from source data
- `curatedCols` (string[]): Array of curated column names (target columns)
  **Returns**: `Mapping[]` - Array of mapping objects
  **Logic**:

1. Safely handles arrays (defensive programming)
2. Creates mappings for each raw column using fuzzy matching
3. Adds system control columns as entity-level metadata
4. Returns combined array of data mappings and control column mappings

**Example**:

```javascript
const mappings = createInitialMappings(
  ["customer_id", "first_name", "email"],
  ["customer_id", "first_name", "email", "updated_at", "version", "is_deleted"]
);
// Returns mappings with fuzzy-matched columns plus control columns
```

### `updateMapping(idx, field, value)`

**Location**: Lines 370-404
**Purpose**: Updates a specific field in a mapping and triggers auto-save
**Parameters**:

- `idx` (number): Index of the mapping to update
- `field` (string): Field to update ("raw" or "curated")
- `value` (string): New value for the field
  **Side Effects**:
- Updates mappings state
- Validates against control column names
- Triggers auto-save for curated field changes
  **Validation**:
- Prevents mapping to reserved control column names
- Shows alert if control column name is used

### `deleteMapping(idx)`

**Location**: Lines 407-421
**Purpose**: Removes a mapping from the list
**Parameters**:

- `idx` (number): Index of the mapping to delete
  **Validation**:
- Prevents deletion of control columns
- Shows alert if attempting to delete control column
  **Side Effects**:
- Updates mappings state
- Triggers auto-save after deletion

### `addMapping()`

**Location**: Lines 423-436
**Purpose**: Adds a new empty mapping for creating new columns
**Returns**: Updates mappings state with new empty mapping object
**New Mapping Structure**:

```javascript
{
  raw: "",
  curated: "",
  autogenerated: false,
  isNewColumn: true
}
```

### `saveNewColumn(idx)`

**Location**: Lines 438-489
**Purpose**: Saves a newly created column with validation
**Parameters**:

- `idx` (number): Index of the new column mapping
  **Validation**:
- Ensures column name is provided
- Prevents use of control column names
- Trims whitespace from column names
  **Process**:

1. Validates column name
2. Updates mapping state
3. Triggers auto-save with new column
4. Marks column as saved in state

## Auto-Save Function

### `autoSaveMappings(currentMappings, currentColumnDescriptions, newlySavedColumn)`

**Location**: Lines 616-677
**Purpose**: Automatically saves all transformation data to backend
**Parameters**:

- `currentMappings` (Mapping[]): Current mapping state (defaults to state)
- `currentColumnDescriptions` (Record<string, string>): Current descriptions (defaults to state)
- `newlySavedColumn` (string|null): Name of newly saved column (optional)
  **Process**:

1. Collects new columns from mappings
2. Updates curated attributes with new columns
3. Collects control columns for metadata
4. Prepares transformation object
5. Saves to backend via API
   **Error Handling**: Silently handles errors to avoid blocking UI

## Data Loading Functions

### `fetchFileColumns()` (useEffect)

**Location**: Lines 90-188
**Purpose**: Fetches schema and metadata for the entity
**Process**:

1. Determines curated entity name
2. Fetches raw schema from API
3. Extracts column names from schema
4. Fetches column metadata (descriptions, data types)
5. Creates initial mappings
6. Handles errors gracefully
   **API Calls**:

- `GET /api/raw-schemas/{entityName}`
- `GET /api/raw-schemas/{entityName}/column-metadata`

### `loadSavedTransformations()` (useEffect)

**Location**: Lines 192-265
**Purpose**: Loads previously saved transformations from backend
**Process**:

1. Fetches saved transformations
2. Restores all state variables
3. Merges descriptions with auto-generated ones
4. Handles missing transformations gracefully
   **API Calls**:

- `GET /api/transformations/{entityName}`
