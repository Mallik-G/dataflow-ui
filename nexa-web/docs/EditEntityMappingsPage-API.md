# EditEntityMappingsPage - API Documentation

## API Endpoints Overview

The `EditEntityMappingsPage` component interacts with several backend API endpoints to manage data transformations and entity mappings. All endpoints follow RESTful conventions and return JSON responses.

## Base URL

All API calls are made relative to the application's base URL (typically `/api`).

## Authentication

All API endpoints require authentication. The component assumes authentication is handled at the application level.

## Endpoints

### 1. Get Raw Entity Schema

**Endpoint**: `GET /api/raw-schemas/{entityName}`
**Purpose**: Retrieves schema information for a raw entity
**Parameters**:

- `entityName` (string, required): URL-encoded entity name (e.g., "raw.customers")

**Request Example**:

```http
GET /api/raw-schemas/raw.customers
```

**Response Structure**:

```typescript
{
  success: boolean;
  schema: {
    schemaAttributes: string[] | Array<{
      name: string;
      type?: string;
      nullable?: boolean;
    }>;
  };
}
```

**Response Example**:

```json
{
  "success": true,
  "schema": {
    "schemaAttributes": [
      "customer_id",
      "first_name",
      "last_name",
      "email",
      "phone"
    ]
  }
}
```

**Error Responses**:

- `404`: Entity not found
- `500`: Server error

**Usage in Component**: Lines 100-102

```javascript
const schemaResponse = await axios.get(
  `/api/raw-schemas/${encodeURIComponent(entityName)}`
);
```

### 2. Get Column Metadata

**Endpoint**: `GET /api/raw-schemas/{entityName}/column-metadata`
**Purpose**: Retrieves column metadata including descriptions and data types
**Parameters**:

- `entityName` (string, required): URL-encoded entity name

**Request Example**:

```http
GET /api/raw-schemas/raw.customers/column-metadata
```

**Response Structure**:

```typescript
{
  success: boolean;
  columnMetadata: Array<{
    columnName: string;
    description: string;
    dataType?: string;
    isGenerated: boolean;
    nullable?: boolean;
    defaultValue?: any;
  }>;
}
```

**Response Example**:

```json
{
  "success": true,
  "columnMetadata": [
    {
      "columnName": "customer_id",
      "description": "Unique identifier for the customer",
      "dataType": "integer",
      "isGenerated": false,
      "nullable": false
    },
    {
      "columnName": "email",
      "description": "Customer's email address",
      "dataType": "string",
      "isGenerated": true,
      "nullable": true
    }
  ]
}
```

**Usage in Component**: Lines 132-136

```javascript
const metadataResponse = await axios.get(
  `/api/raw-schemas/${encodeURIComponent(entityName)}/column-metadata`

```

### 3. Get Saved Transformations

**Endpoint**: `GET /api/transformations/{entityName}`
**Purpose**: Retrieves previously saved transformation configurations
**Parameters**:

- `entityName` (string, required): URL-encoded entity name

**Request Example**:

```http
GET /api/transformations/raw.customers
```

**Response Structure**:

```typescript
{
  success?: boolean;
  transformations: {
    mappings: Mapping[];
    columnRules: Record<string, any>;
    operatorRules: Record<string, any>;
    concatenationRules: ConcatenationRule[];
    entityNLPRules: any[];
    columnDescriptions: Record<string, string>;
    curatedEntityName: string;
    curatedAttributes: string[];
    fileData?: FileData;
    newColumns?: string[];
    entityLevelMetadata?: {
      controlColumns: string[];
      controlColumnsCount: number;
      note: string;
    };
  };
}
```

**Response Example**:

```json
{
  "transformations": {
    "mappings": [
      {
        "raw": "customer_id",
        "curated": "customer_id",
        "autogenerated": true
      },
      {
        "raw": "first_name",
        "curated": "first_name",
        "autogenerated": false
      }
    ],
    "columnRules": {},
    "operatorRules": {},
    "concatenationRules": [],
    "entityNLPRules": [],
    "columnDescriptions": {
      "customer_id": "Unique identifier for the customer",
      "first_name": "Customer's first name"
    },
    "curatedEntityName": "curated.customers",
    "curatedAttributes": ["customer_id", "first_name", "last_name", "email"]
  }
}
```

**Usage in Component**: Lines 196-198

```javascript
const response = await axios.get(
  `/api/transformations/${encodeURIComponent(entityName)}`
);
```

### 4. Save Transformations

**Endpoint**: `POST /api/transformations/save`
**Purpose**: Saves transformation configuration to backend
**Request Body**:

```typescript
{
  entityName: string;
  transformations: {
    entityName: string;
    curatedEntityName: string;
    rawAttributes: string[];
    curatedAttributes: string[];
    mappings: Mapping[];
    columnRules: Record<string, any>;
    operatorRules: Record<string, any>;
    concatenationRules: ConcatenationRule[];
    entityNLPRules: any[];
    columnDescriptions: Record<string, string>;
    fileData?: FileData;
    newColumns: string[];
    entityLevelMetadata: {
      controlColumns: string[];
      controlColumnsCount: number;
      note: string;
    };
  };
}
```

**Request Example**:

```json
{
  "entityName": "raw.customers",
  "transformations": {
    "entityName": "raw.customers",
    "curatedEntityName": "curated.customers",
    "rawAttributes": ["customer_id", "first_name", "last_name"],
    "curatedAttributes": [
      "customer_id",
      "first_name",
      "last_name",
      "updated_at"
    ],
    "mappings": [
      {
        "raw": "customer_id",
        "curated": "customer_id",
        "autogenerated": true
      }
    ],
    "columnRules": {},
    "operatorRules": {},
    "concatenationRules": [],
    "entityNLPRules": [],
    "columnDescriptions": {
      "customer_id": "Unique identifier for the customer"
    },
    "newColumns": [],
    "entityLevelMetadata": {
      "controlColumns": ["_ingest_timestamp", "_source_system"],
      "controlColumnsCount": 2,
      "note": "Control columns are preserved in mappings for data lineage"
    }
  }
}
```

**Response Structure**:

```typescript
{
  success: boolean;
  message?: string;
  savedAt?: string;
}
```

**Response Example**:

```json
{
  "success": true,
  "message": "Transformations saved successfully",
  "savedAt": "2024-01-15T10:30:00Z"
}
```

**Usage in Component**: Lines 672-675

```javascript
await axios.post("/api/transformations/save", {
  entityName: entityName,
  transformations: transformations,
});
```

## Data Types

### Mapping Object

```typescript
interface Mapping {
  raw: string; // Source column name
  curated: string; // Target column name
  autogenerated: boolean; // Whether mapping was auto-generated
  isNewColumn?: boolean; // Whether this is a newly created column
  isControlColumn?: boolean; // Whether this is a system control column
  isEntityLevel?: boolean; // Whether this is entity-level metadata
}
```

### ConcatenationRule Object

```typescript
interface ConcatenationRule {
  id: number; // Unique identifier
  sourceColumns: string[]; // Source columns to concatenate
  targetColumn: string; // Target column name
  separator: string; // Separator character
}
```

### FileData Object

```typescript
interface FileData {
  key: string; // File path/key in storage
  name: string; // Original file name
  size: number; // File size in bytes
  lastModified: Date; // Last modification date
}
```

```
                                    → GET /api/raw-schemas/{entityName}/column-metadata
                                    → createInitialMappings()
```

### 2. State Restoration

```
Component Mount → loadSavedTransformations() → GET /api/transformations/{entityName}
                                          → Restore State Variables
```

### 3. User Interactions

```
User Action → updateMapping() → autoSaveMappings() → POST /api/transformations/save
User Action → saveNewColumn() → autoSaveMappings() → POST /api/transformations/save

```
